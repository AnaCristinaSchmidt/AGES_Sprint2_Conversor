
## 💱 Sprint 2 – Converter with API

**Made by:** Fernando Acauan, Thiago Tarantino, Ana Cristina Schmidt, Lorenzo Bueno.

In this sprint of the **AGES Study Group**, the challenge was to develop a project that consumed an **external API**, with a suggested theme of **Conversion**.

The group created a **Conversion application**. The choice was motivated by the technical challenge and the potential for learning in the use of APIs.

The project lasted about **two weeks**, and each member faced different obstacles along the way. For me, this sprint was especially significant, as I was able to **coordinate the group**, actively contribute and ensure that the delivery was successful.
